# Thiệp cưới — Nguyễn Văn A & Nguyễn Thị B

Website thiệp cưới một trang, responsive, dùng HTML/CSS/JavaScript thuần.

## Chạy để kiểm thử

Mở `index.html` trực tiếp trong trình duyệt. Không cần cài đặt phụ thuộc.

## Kiểm tra nhanh

```powershell
node --check script.js
```

Ảnh trong `assets/` là ảnh minh họa tạo bằng AI, không phải ảnh thật của cô dâu và chú rể.
